
# Books Scraper

## Purpose
This project scrapes book data from [Books to Scrape](http://books.toscrape.com) and saves it into a CSV file with details such as title, price, rating, and availability.

## Features
- Scrapes book data from multiple pages
- Saves data into `books.csv`

## How to run
1. Install dependencies: `pip install -r requirements.txt`
2. Run the scraper: `python main.py`
3. Data will be saved to `books.csv`.

## Future Improvements
- Add functionality to send email alerts if book prices drop.
- Expand to scrape more categories or other websites.
